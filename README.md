# Violet Night

Site da Violet Night, banda para casamentos e eventos no Rio de Janeiro.

Página única, feita em HTML e CSS puros (mobile first), sem dependências.

## Estrutura

- `index.html` — a página inteira (estilos no topo do arquivo, comentados em português)
- `assets/` — logo, fotos dos integrantes, fotos e vídeo da pista

## Como editar

- **Cores e fontes:** bloco `:root` no início do `<style>` em `index.html`.
- **WhatsApp:** troque `5521967152172` em todos os links `wa.me`.
- **Textos:** cada seção está marcada com um comentário `<!-- ===== NOME ===== -->`.
- **Depoimento:** procure "Espaço reservado para o depoimento" e troque pelo texto das noivas.

## Publicar

Funciona em qualquer hospedagem de site estático (GitHub Pages, Netlify, Vercel).
No GitHub Pages: Settings → Pages → Branch `main` / pasta raiz.
